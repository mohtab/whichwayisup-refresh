# Omarchy emblem

`omarchy-icon.png` is an unmodified copy of `icon.png` from
[basecamp/omarchy v4.0.3](https://github.com/basecamp/omarchy/blob/v4.0.3/icon.png),
verified byte-for-byte against the versioned upstream file on September 13, 2026.

Copyright (c) David Heinemeier Hansson. The upstream MIT notice is preserved in
`licenses/omarchy-MIT.txt`. Omarchy naming and branding do not imply affiliation
or endorsement. This game is an independent homage.

The game scales, pulses and adds a glow around the mark at runtime. The source
image is retained intact; no AI-generated approximation of the logo is used.
