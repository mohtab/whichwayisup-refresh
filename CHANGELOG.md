# What’s new

## 0.4.0rc4 — Linux preview

A more comfortable way to revisit Which Way Is Up?, with clearer progress and
more control over how the game looks.

- Continue to your next unfinished stage and see completed stages and local best times.
- Choose a compact HUD or board-only view, with sharper gameplay and smoother interface text.
- Find display, audio, controls, and gameplay options in grouped settings.
- Enjoy quieter platform textures and subtle sprite edges; bright outlines are optional.
- Reset movement keys and navigate menus with a controller’s D-pad.
- Get clearer retry, save-failure, and campaign-completion messages.
- Keep saved best-time replays safe when a later run sets a new record.
- Fix a Wayland rendering problem that could hide the whole playfield.
- Find Codex (OpenAI) explicitly credited for AI coding assistance.
- Use clearer download instructions, player guides, and bug-report forms.

This preview is for Linux. Physical controller, audio, suspend/resume, and
multiple-monitor testing still benefit from player feedback. Automated checks are
documented in [release acceptance](docs/RELEASE_ACCEPTANCE.md).
